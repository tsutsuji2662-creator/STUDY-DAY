# StudyDay

国家一般職試験の勉強を続けるための、りんごモチーフの学習記録アプリです。

## 主な機能
- 試験日までのカウントダウン
- 1日5時間を基本にした学習目標
- 25分/5分、50分/10分のポモドーロ
- 一時停止・途中終了・手入力
- 科目別の学習時間
- 今日/今週/累計の残り時間
- 🍎 セット数による小さな目標
- カレンダー（0時間、1〜3時間、3〜5時間、5時間以上）
- 連続勉強日数
- 累計勉強時間を主役にした達成画面
- バッジ
- ごほうびチケット
- localStorageによる端末内保存
- PWA用 manifest / service worker

## iPhoneで使う
HTMLをファイルアプリ内で直接開くとJavaScriptが動かない環境があります。
このプロジェクトをHTTPSで公開すると、Safariからホーム画面に追加できるPWAとして使えます。
